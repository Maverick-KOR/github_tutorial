## Flutter View Switching Example

`view_switching_example.dart` 파일은 노션과 유사하게 데이터베이스 뷰를 전환하는 간단한 예제를 제공합니다. `BottomNavigationBar`를 통해 표, 캘린더, 타임라인, 보드 화면을 옵션으로 선택할 수 있습니다.

```dart
import 'package:flutter/material.dart';
// ... 위젯 코드 생략 (파일 참고)
```

이 예제는 기본적인 개념을 보여주므로 실제 프로젝트에서는 각 뷰를 실제 데이터와 연결하고, 더 복잡한 UI/UX 로직을 구현해야 합니다.
